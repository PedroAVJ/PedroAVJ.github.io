# Pedro Antonio

My personal site: [pedroavj.github.io](https://pedroavj.github.io).

Static HTML and CSS, hosted by GitHub Pages. It follows the device's light or dark appearance, works without JavaScript, and loads its fonts locally.

Edit `index.html` for content and `style.css` for presentation. Selected work is manually ordered. Link to public source and setup instructions, and distinguish development from public release. Keep employer names and private records off this page.

Run a local preview with `python3 -m http.server 4173 --bind 127.0.0.1`. GitHub Pages serves the root of the `main` branch.
